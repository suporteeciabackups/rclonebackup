Política de Privacidade

Última atualização: 20/10/2026

1. Finalidade

O rclonebackup disponibiliza serviços de backup automatizado para Google Drive, mediante autorização dos clientes.

2. Dados acedidos

O serviço solicita permissões de acesso ao Google Drive necessárias à execução dos backups contratados.

3. Utilização dos dados

Os dados acedidos são utilizados para realizar as operações de backup autorizadas pelo cliente.

4. Armazenamento e segurança

As credenciais de autorização OAuth devem ser protegidas contra acessos não autorizados.

5. Partilha de dados

O tratamento e a eventual partilha de dados devem respeitar as condições acordadas com cada cliente.

6. Revogação do acesso

O cliente pode revogar o acesso do aplicativo através das configurações de segurança da sua conta Google.
